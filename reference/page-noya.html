New value proposition

We pivoted Noya’s value proposition to be a modular AI workspace where users can build, evolve, and maintain products over time. The new design highlights Noya’s composability and connected tools.

Defining the visual language

We wanted Noya to feel vibrant, expressive, and modular, so I developed an illustration style that reflects the system’s flexibility.

Bringing the ecosystem to life with motion

Showing how Noya’s tools connect as one system through animation, making modularity feel concrete rather than abstract.

Introducing tools, efficiently

Modular layout that introduces each tool through concise taglines and contextual examples, helping users understand their role without breaking the page flow.

Maintain visual consistency across pages

To maintain visual cohesion, we used Noya’s own Vector Art tool to generate blog graphics, reinforcing the idea that the product can power its own marketing.

Reframing tools as file types

Takeaways

Thinking in systems

Working with Noya pushed me to think beyond individual features and focus on systems, narratives, and long-term product thinking. Early on, I realized that the challenge wasn’t just designing powerful tools, but helping users understand how those tools fit together as a coherent workspace. This led me to reframe Noya from a collection of AI-powered utilities into a modular system where each tool functions as a composable building block.
